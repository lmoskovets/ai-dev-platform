# AI Dev Platform

Платформа связывает сотрудников, проекты, агентов и правила компании для AI-first разработки.

## Первая версия

- Учётные записи сотрудников и вход по приглашению.
- Проекты с несколькими GitHub-репозиториями и рабочими инструкциями.
- Доступ сотрудника и его агента только к разрешённым проектам и данным.
- Подготовка рабочего окружения агентом по инструкциям проекта.
- Отзыв доступа сотрудника и его агента при уходе из компании.
- Отдельный модуль интеграций, начиная с GitHub.

Источник требований: [customer-requirements.md](customer-requirements.md).

## Состояние проекта

В репозитории есть требования, проектные скиллы и инструкции для агентов.
Стек, архитектура и способ подключения агента пока не выбраны.
Кода приложения, сборки, тестов и CI пока нет.

## Начало работы

```sh
git clone https://github.com/lmoskovets/ai-dev-platform.git
cd ai-dev-platform
```

Перед реализацией прочитайте требования и согласуйте технические решения и границы задачи.
Команды установки зависимостей, запуска и проверок добавляйте вместе с соответствующим кодом.

## Работа с репозиторием

- Создавайте отдельные ветки и pull requests для изменений.
- Фиксируйте lock-файлы выбранного менеджера зависимостей в Git.
- Храните секреты в локальных `.env`-файлах.
- Описывайте переменные окружения в `.env.example` без реальных секретов.
- Ведите задачи и спецификации в [GitHub Issues](https://github.com/lmoskovets/ai-dev-platform/issues).
